# ⛏️ Data Mining Course Project (Web Scraping, Python & WEKA)

A comprehensive data mining project implementing the full Knowledge Discovery in Databases (KDD) pipeline. This project covers data collection via automated web scraping, data preprocessing, feature analysis, and predictive modeling using both programmatic approaches (**Python**) and specialized data mining software (**WEKA**).

## 🛠️ Tech Stack & Toolset

* **Data Scraping & Extraction:** Python (BeautifulSoup / Requests / Selenium) inside `scraping_data .ipynb`.
* **Data Processing & Analytics:** Python 🐍 (`main.ipynb`) utilizing Pandas, NumPy, Matplotlib, and Seaborn.
* **Advanced Data Mining Tools:** **WEKA** (Waikato Environment for Knowledge Analysis) for visual modeling, evaluation metrics, and comparative algorithm analysis.

---

## 🚀 Data Mining Pipeline (Workflow)

1. **Data Acquisition (Web Scraping):** Dynamically extracting raw data fields from target web platforms to build a custom dataset.
2. **Data Cleaning & Preprocessing:** Handling missing attributes, removing duplicate records, smoothing noisy data, and preparing datasets for model ingestion.
3. **Programmatic Modeling (Python):** Executing data exploratory processes and testing machine learning baselines.
4. **Visual Data Mining (WEKA):** Loading preprocessed data into WEKA to execute advanced mining tasks (such as Decision Trees, Naive Bayes, or Clustering), analyzing confusion matrices, and comparing model accuracies.
